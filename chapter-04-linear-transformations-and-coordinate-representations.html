4. Linear transformations and coordinate representations

A document system compresses three feature counts into two summaries: the first adds features one and two, and the second adds features two and three. Different documents can now produce exactly the same summaries. The compression may be useful, but a downstream classifier cannot distinguish inputs that it has merged. A linear map identifies the erased directions exactly and separates this information loss from the coordinates used to describe it.

Lectures 7–10 supply geometric transformations, domains and codomains, range and kernel, matrices from basis images, rectangular maps, and composition. The running compression, its solution families, and the worked numerical study are original constructions. Conventional rotation, reflection, and shear matrices are also discussed in the recordings.

4.1 A linear transformation preserves specified combinations Lecture 7 · 06:15 Lecture 8 · 33:37

A map $T:V\to W$ assigns exactly one element of the set $W$ to each element of $V$. The set $V$ is its domain; the specified target set $W$ is its codomain. The vector $T(x)$ is the image of the particular input $x$. The set of all such outputs is the image or range, written $\operatorname{im}T=\{T(x):x\in V\}$. The image can be strictly smaller than the codomain.

For real vector spaces $V,W$, the map is linear when

$$T(\alpha u+\beta v)=\alpha T(u)+\beta T(v) \quad\text{for every }u,v\in V,\ \alpha,\beta\in\mathbb R.$$

Setting coefficients appropriately gives preservation of sums and scalar multiples. Conversely, those two preservation rules imply the displayed equation by applying one after the other. Linearity is a statement about all inputs and all coefficients, not a visual judgment that an output graph looks straight.

A linear map sends zero to zero: $T(0)=T(0+0)=T(0)+T(0)$, so subtracting $T(0)$ gives $T(0)=0$. This condition is necessary but not sufficient. The scalar map $f(x)=x^2$ fixes zero yet satisfies $f(1+1)=4\ne2=f(1)+f(1)$. A translation $g(x)=x+b$ with $b\ne0$ fails immediately because $g(0)=b$. A map $x\mapsto Ax+b$ is affine; it is linear exactly when its offset is zero.

The running compression is

$$T:\mathbb R^3\to\mathbb R^2,\qquad T(x_1,x_2,x_3)^\top=(x_1+x_2,\ x_2+x_3)^\top.$$

For each output coordinate, combining inputs with coefficients $\alpha,\beta$ combines the corresponding sums with those coefficients. Thus the map is linear. Although feature counts may be nonnegative in the application, the ambient domain is $\mathbb R^3$ so that differences and signed perturbations are included. The physical observation set and the mathematical domain need not coincide.

The reference Deisenroth, Faisal, and Ong, Section 2.7, printed pages 48–49, defines linearity and the distinctions among injective, surjective, and bijective maps. We develop those properties through the compression rather than treating every rectangular matrix as an automatically reversible representation.

4.2 The matrix columns are transformed basis vectors Lecture 9 · 17:11

Let $e_1,\ldots,e_n$ be the standard basis of $\mathbb R^n$. Since $x=\sum_jx_je_j$, linearity gives $T(x)=\sum_jx_jT(e_j)$. When the outputs belong to $\mathbb R^m$, place $T(e_j)$ in column $j$ of an $m\times n$ matrix $A$. By the definition of matrix multiplication, the combination on the right is $Ax$. Every linear map between these coordinate spaces therefore has a matrix representation.

The representation is unique in the specified bases. If two matrices $A$ and $B$ give the same transformation for every input, then $Ae_j=Be_j$ for every standard vector. These are their respective $j$th columns, so all corresponding columns agree and $A=B$. Conversely, any fixed matrix defines a linear map because matrix multiplication distributes over vector addition and scalar multiplication.

For the compression, the standard vectors map to $(1,0)^\top$, $(1,1)^\top$, and $(0,1)^\top$, respectively. Hence

$$A=\begin{bmatrix}1&1&0\\0&1&1\end{bmatrix},\qquad T(x)=Ax.$$

The two rows compute the two summaries, while the three columns describe the effects of individual input coordinates. A common implementation mistake is to place basis images in rows. Here that would produce a $3\times2$ matrix with the wrong domain and codomain. Dimensions can catch the error before any numerical result is interpreted.

This principle extends beyond geometric arrows. Let $\mathcal P_2$ be real polynomials of degree at most two, and let $\mathcal P_1$ be those of degree at most one, both including zero. Differentiation $D:\mathcal P_2\to\mathcal P_1$ is linear because differentiating a sum or a scalar multiple preserves the corresponding operation. In input basis $(1,t,t^2)$ and output basis $(1,t)$, the images $0,1,2t$ give the matrix

$$[D]=\begin{bmatrix}0&1&0\\0&0&2\end{bmatrix}.$$

Multiplying by the coefficient vector $(a,b,c)^\top$ returns $(b,2c)^\top$, the coefficients of the derivative of $a+bt+ct^2$. Input and output coordinates describe functions, not positions. The same column rule still applies.

4.3 Familiar geometric operations expose different mechanisms Lecture 7 · 11:41

The identity matrix leaves every vector unchanged, while the zero matrix sends every vector to zero. Between these extremes, a map may change orientation, scale, or shape while remaining invertible. The following two-dimensional examples use column inputs $(x,y)^\top$.

OperationMatrixOutput and interpretation
Swap coordinates$\begin{bmatrix}0&1\\1&0\end{bmatrix}$$(y,x)^\top$; reflection across the line $x=y$.
Reflect across the horizontal axis$\begin{bmatrix}1&0\\0&-1\end{bmatrix}$$(x,-y)^\top$; horizontal coordinate retained.
Reflect across the vertical axis$\begin{bmatrix}-1&0\\0&1\end{bmatrix}$$(-x,y)^\top$; vertical coordinate retained.
Counterclockwise quarter-turn$\begin{bmatrix}0&-1\\1&0\end{bmatrix}$$(-y,x)^\top$; $e_1$ goes to $e_2$, and $e_2$ to $-e_1$.
Horizontal shear$S_\gamma=\begin{bmatrix}1&\gamma\\0&1\end{bmatrix}$$(x+\gamma y,y)^\top$; higher horizontal rows shift more.
Axis scaling$\begin{bmatrix}a&0\\0&b\end{bmatrix}$$(ax,by)^\top$; scaling can collapse an axis if its factor is zero.

Each row follows by multiplying the matrix by the two standard basis vectors. For the shear, the horizontal direction remains fixed and $e_2$ acquires horizontal component $\gamma$. A unit square therefore becomes a parallelogram. Applying $S_{-\gamma}$ reverses the operation, as $S_{-\gamma}S_\gamma=I$. A slanted drawing has changed shape without losing a dimension.

A shear can approximate the geometric slant associated with oblique text, as illustrated in the lecture. It is not a complete model of the design differences between arbitrary upright and italic typefaces. The exact mathematical claim is the coordinate displacement $x\mapsto x+\gamma y$ and its inverse, independent of font-design conventions.

For a counterclockwise rotation through angle $\theta$, the images of $e_1$ and $e_2$ are $(\cos\theta,\sin\theta)^\top$ and $(-\sin\theta,\cos\theta)^\top$. Thus

$$R_\theta=\begin{bmatrix}\cos\theta&-\sin\theta\\ \sin\theta&\cos\theta\end{bmatrix}.$$

Multiplication gives $R_\theta^\top R_\theta=I$ using $\cos^2\theta+\sin^2\theta=1$ and cancellation of the cross terms. Therefore $\|R_\theta x\|_2^2=x^\top R_\theta^\top R_\theta x=\|x\|_2^2$: rotation preserves Euclidean length. A shear generally does not. For example, $S_1e_2=(1,1)^\top$ has length $\sqrt2$, whereas $e_2$ has length one. Linearity alone does not guarantee length or angle preservation.

4.4 The range is the set of attainable summaries Lecture 8 · 08:20

For a matrix $A=[a_1\cdots a_n]$, the identity $Ax=\sum_jx_ja_j$ proves that $\operatorname{im}A$ is the span of its columns. This is its column space. It is a subspace of the output space $\mathbb R^m$. More abstractly, if $y_1=T(x_1)$ and $y_2=T(x_2)$, then $\alpha y_1+\beta y_2=T(\alpha x_1+\beta x_2)$ lies in the image; zero is also present.

The running compression reaches every pair $(u,v)^\top\in\mathbb R^2$, because $(u,0,v)^\top$ maps to it. Its range is therefore its whole codomain. A map with this property is surjective or onto. This is an existence statement: every permitted output has at least one input. It says nothing yet about uniqueness of that input.

Now consider the linear expansion $E:\mathbb R^2\to\mathbb R^3$ defined by $E(u,v)=(u,u+v,v)^\top$. Its range is the plane of vectors satisfying $z_2=z_1+z_3$. Every output satisfies this relation, and every vector satisfying it is obtained from $(u,v)=(z_1,z_3)$. The map is not onto $\mathbb R^3$, even though each of its outputs has three coordinates. Adding stored coordinates has not manufactured a third independent degree of freedom.

For a line $L=\operatorname{span}(v)$ through zero, linearity gives $T(L)=\operatorname{span}(T(v))$. If $T(v)\ne0$, the image is a line; if $T(v)=0$, it is the zero subspace. A plane can similarly become a plane, line, or zero. A linear transformation preserves the subspace property but need not preserve its dimension. This qualifies the tempting geometric claim that lines and planes always retain their sizes under a linear map.

4.5 The kernel identifies distinctions that disappear Lecture 8 · 20:55

The kernel of $T$ is $\ker T=\{x\in V:T(x)=0_W\}$. It lies in the input space, whereas the image lies in the output space. In matrix coordinates, it is also called the null space: the solutions of $Ax=0$. For an $m\times n$ matrix, $x$ has $n$ coordinates and the zero on the right has $m$ coordinates.

The kernel is a subspace. It contains zero, and if $T(u)=T(v)=0$, then $T(\alpha u+\beta v)=\alpha0+\beta0=0$. For the compression, the equations are $x_1+x_2=0$ and $x_2+x_3=0$. Writing $x_1=t$ gives $x_2=-t$ and $x_3=t$, so

$$\ker A=\operatorname{span}\left(\begin{bmatrix}1\\-1\\1\end{bmatrix}\right).$$

Adding this direction to any input leaves its summaries unchanged. In particular, $(1,2,3)^\top$ and $(2,1,4)^\top$ both map to $(3,5)^\top$. Both are nonnegative count vectors, so the ambiguity is not merely an artifact of allowing impossible negative observations. The compression has merged two admissible inputs.

More generally, $T(x)=T(y)$ exactly when $T(x-y)=0$, or $x-y\in\ker T$. Thus the kernel describes all pairs of indistinguishable inputs through their difference. A map is injective or one-to-one when equal outputs force equal inputs. For a linear map this is equivalent to $\ker T=\{0\}$. One direction follows from injectivity and $T(0)=0$; the other follows by applying the zero-kernel condition to $x-y$.

If $Ax=b$ has one solution $x_0$, its complete solution set is $x_0+\ker A$. Indeed $A(x_0+v)=b$ when $Av=0$, and subtracting $Ax_0=b$ from any other solution gives a null vector. For the target $(3,5)^\top$, every solution is $(1,2,3)^\top+t(1,-1,1)^\top$. Its solution set is an affine line, not a subspace, because the target is nonzero.

4.6 Rank and nullity account for every input degree of freedom Lecture 10 · 42:29

The rank of a linear map is $\dim\operatorname{im}T$. Its nullity is $\dim\ker T$. In finite-dimensional input space $V$, the rank–nullity identity is

$$\dim V=\operatorname{rank}T+\operatorname{nullity}T.$$

To prove it, let $k_1,\ldots,k_r$ be a basis of the kernel and extend this to a basis $k_1,\ldots,k_r,v_1,\ldots,v_s$ of $V$. Every input expands in this basis. Applying $T$ eliminates the kernel terms, so every output is a combination of $T(v_1),\ldots,T(v_s)$. These images therefore span the range.

They are also independent. If $\sum_j a_jT(v_j)=0$, then $\sum_j a_jv_j$ belongs to the kernel and can be expressed as $\sum_i b_ik_i$. Move this expression to one side. Independence of the full input basis forces every $a_j$ and $b_i$ to vanish. The range consequently has dimension $s$, while the kernel has dimension $r$ and $V$ has dimension $r+s$. This proves the identity without interpreting “information” as an undefined numerical quantity.

Our compression has nullity one and rank two. Its input dimension is three, and the identity gives $3=1+2$. The expansion $E$ has zero kernel: $E(u,v)=0$ forces $u=v=0$. It therefore has rank two, consistent with its planar range. For any matrix $\mathbb R^n\to\mathbb R^m$, rank is at most $\min(n,m)$, since the image cannot have dimension exceeding either the number of input basis images or its containing output space.

If $n\gt m$, injectivity is impossible: nullity is at least $n-m$. If $n\lt m$, surjectivity is impossible: rank is at most $n$. However, a map from a higher-dimensional space to a lower-dimensional space need not be onto. The zero map is a counterexample. Full row rank, rather than shape alone, establishes surjectivity. A square map is injective exactly when it is surjective; rank–nullity shows both are equivalent to full rank.

4.7 Composition explains the order of matrix products Lecture 10 · 43:11

Let $T:U\to V$ and $S:V\to W$ be linear. Their composition $S\circ T$ applies $T$ first and $S$ second. Applying the two preservation laws in turn gives $S(T(\alpha x+\beta y))=\alpha S(T(x))+\beta S(T(y))$, so the composition is linear. If their matrices are $A$ and $B$, then its output is $B(Ax)=(BA)x$: the rightmost factor acts first.

Our expansion has matrix $E=\begin{bmatrix}1&0\\1&1\\0&1\end{bmatrix}$. Compressing after expanding gives

$$AE=\begin{bmatrix}2&1\\1&2\end{bmatrix}=M.$$

The shape is $2\times2$: inputs and outputs each have two coordinates. Reversing the operations gives $EA$, a $3\times3$ matrix. Even when both orders have the same shape, their actions may differ. For the quarter-turn $R$ and unit shear $S_1$, input $(1,2)^\top$ gives $RS_1x=(-2,3)^\top$, while $S_1Rx=(-1,1)^\top$. Matrix multiplication is associative, allowing unambiguous successive application, but generally not commutative.

A later linear map cannot restore a distinction already erased: if $Av=0$, then $BAv=B0=0$. Thus $\ker A\subseteq\ker(BA)$. This is the exact obstruction facing the classifier in the opening example. Additional data or a more informative representation can help; processing the same compressed summaries alone cannot distinguish merged inputs.

4.8 Changing coordinates changes the matrix, not the map Lecture 9 · 37:28

For a general finite-dimensional space, choose an ordered input basis $\mathcal B=(b_1,\ldots,b_n)$ and output basis $\mathcal C=(c_1,\ldots,c_m)$. If $T(b_j)=\sum_i a_{ij}c_i$, then column $j$ of the representation matrix contains the coefficients $a_{ij}$. For any input coefficient vector $[x]_{\mathcal B}$, expanding $x$ and applying linearity yields $[T(x)]_{\mathcal C}=A[x]_{\mathcal B}$. The column entries are output coordinates, not necessarily the raw components of an abstract vector.

Suppose the old and new coordinate columns are related by $x=P x'$ and $y=Q y'$, where the square matrices $P,Q$ are invertible changes of basis. Starting from $y=Ax$, substitute these relations to get $Qy'=APx'$. Multiplying by $Q^{-1}$ gives

$$y'=Q^{-1}APx',\qquad A'=Q^{-1}AP.$$

The inverse on the left converts the computed output to its new coordinates. The factor on the right converts the new input coordinates to the old ones before applying the map. If the same space and same basis change are used at both ends, $Q=P$ and the formula becomes $A'=P^{-1}AP$. This relation is called similarity of the two square matrices.

For $M=AE$, take $P=\begin{bmatrix}1&1\\1&-1\end{bmatrix}$, whose columns describe the common and difference directions. Direct multiplication gives $M(1,1)^\top=3(1,1)^\top$ and $M(1,-1)^\top=(1,-1)^\top$. Therefore $P^{-1}MP=\operatorname{diag}(3,1)$, a diagonal matrix with these two scaling factors. The physical map is unchanged; its action is easier to describe in a basis aligned with directions it does not mix. These are the eigenvector directions studied next.

The reference Sections 2.7.1–2.7.2, printed pages 51–55, gives the basis-image column rule and the change-of-basis formula. The preceding substitutions make the direction of each coordinate conversion explicit, so the formula need not be memorized as an unexplained order of inverses.

4.9 An executable coordinate audit

This fixed-data NumPy program verifies a null direction, the noncommutativity calculation, and two independent descriptions of a composed map. It changes no files and accepts no external input. Solving $PZ=MP$ obtains the changed-basis matrix without explicitly forming an inverse. Assertions compare against exact small-case algebra, while output shows the same quantities to the reader.

import numpy as np

A = np.array([[1., 1., 0.], [0., 1., 1.]])
E = np.array([[1., 0.], [1., 1.], [0., 1.]])
x = np.array([1., 2., 3.])
null_vector = np.array([1., -1., 1.])
assert np.array_equal(A @ null_vector, np.zeros(2))
assert np.array_equal(A @ (x + null_vector), A @ x)
M = A @ E
assert np.array_equal(M, [[2., 1.], [1., 2.]])
P = np.array([[1., 1.], [1., -1.]])
changed = np.linalg.solve(P, M @ P)
assert np.allclose(changed, np.diag([3., 1.]))
R = np.array([[0., -1.], [1., 0.]])
S = np.array([[1., 1.], [0., 1.]])
v = np.array([1., 2.])
assert not np.allclose(R @ S @ v, S @ R @ v)
print("compressed features:", A @ x)
print("quarter-turn after shear:", R @ S @ v)
print("shear after quarter-turn:", S @ R @ v)
print("matrix in common/difference coordinates:")
print(changed)

4.10 Problems and worked solutions

Problem 1 · Zero is only a necessary test

Determine whether $f(x,y)=(x+y,xy)^\top$ and $g(x,y)=(2x-y+1,x)^\top$ are linear. Exhibit a violated law for each failure.

Solution

The first fixes zero, but $f(1,0)=(1,0)^\top$ and $f(0,1)=(1,0)^\top$, whose sum is $(2,0)^\top$. Their input sum maps to $f(1,1)=(2,1)^\top$, violating additivity. The second has $g(0,0)=(1,0)^\top$ and therefore cannot be linear. It is an affine map with offset $(1,0)^\top$. A zero-image test rules out the second quickly but cannot certify the first.

Problem 2 · Rectangular map and its exact range

Find the matrix, kernel, and range of $F(x,y)=(2x-y,x+3y,x)^\top$. Is it injective? Is it onto $\mathbb R^3$?

Solution

The standard-basis images are $(2,1,1)^\top$ and $(-1,3,0)^\top$, so these are the two columns. A zero output has third coordinate $x=0$ and then first coordinate $-y=0$, giving a zero kernel and injectivity. Every output $z$ satisfies $3z_1+z_2=7z_3$, since $3(2x-y)+(x+3y)=7x$. Conversely, for a vector satisfying that equation, choose $x=z_3$ and $y=2z_3-z_1$; the second output becomes $7z_3-3z_1=z_2$. Thus the range is exactly that plane, not all of $\mathbb R^3$.

Problem 3 · A family of indistinguishable observations

Find all inputs mapping to $(3,5)^\top$ under the running compression. Which of them have nonnegative coordinates? Explain the consequence for a classifier receiving only the summaries.

Solution

The family is $(1+t,2-t,3+t)^\top$. Nonnegativity requires $t\ge-1$, $t\le2$, and $t\ge-3$, so the feasible range is $-1\le t\le2$. There are many distinct nonnegative inputs with the same summaries. Any deterministic classifier using only those summaries assigns all of them the same prediction. If their desired labels differ, at least one must be wrong. This conclusion uses equality of the observed representation, not an assumption about a particular training algorithm.

Problem 4 · Differentiation and rank–nullity

Regard differentiation as an operator $\mathcal P_2\to\mathcal P_2$ using basis $(1,t,t^2)$ at both ends. Find its matrix, kernel, and image, and verify rank–nullity.

Solution

The basis images are $0,1,2t$, giving $\begin{bmatrix}0&1&0\\0&0&2\\0&0&0\end{bmatrix}$. A polynomial $a+bt+ct^2$ has zero derivative precisely when $b=c=0$, so the kernel is the one-dimensional space of constants. Every polynomial $r+st$ is a derivative: choose $rt+(s/2)t^2$. The image is therefore $\mathcal P_1$, of dimension two. The input has dimension three and $3=1+2$. Changing the codomain from $\mathcal P_1$ to $\mathcal P_2$ makes the same operation non-surjective without changing its possible outputs.

Problem 5 · A later stage cannot undo a collapse

Prove $\ker A\subseteq\ker(BA)$ for compatible linear maps. Can the inclusion be strict? Relate the result to the ranks of $A$, $B$, and $BA$.

Solution

If $Av=0$, then $(BA)v=B(Av)=B0=0$, proving inclusion. It can be strict: take $A=I$ and $B=0$, so the first kernel is zero and the composite kernel is the whole domain. Rank–nullity on the common input domain gives $\operatorname{rank}(BA)\le\operatorname{rank}A$. Also $\operatorname{im}(BA)\subseteq\operatorname{im}B$, so $\operatorname{rank}(BA)\le\operatorname{rank}B$. A later stage can discard additional distinctions but cannot create distinctions among already identical intermediate outputs.

Problem 6 · Coordinate conversion versus a new operation

For $M=\begin{bmatrix}2&1\\1&2\end{bmatrix}$ and $P=\begin{bmatrix}1&1\\1&-1\end{bmatrix}$, find the new coordinates of $x=(3,1)^\top$, apply the diagonal representation, and convert back. Compare with direct multiplication.

Solution

Solving $P x'=x$ gives $x'_1+x'_2=3$ and $x'_1-x'_2=1$, so $x'=(2,1)^\top$. The changed-basis matrix is $\operatorname{diag}(3,1)$, giving output coordinates $(6,1)^\top$. Converting back gives $P(6,1)^\top=(7,5)^\top$. Direct multiplication gives $Mx=(2\cdot3+1,3+2\cdot1)^\top=(7,5)^\top$. The two calculations represent the same operation; using the diagonal matrix directly on the old coordinates would instead give $(9,1)^\top$ and would implement a different map.

Linearity supplies exact preservation and dimension statements. It does not guarantee that a representation preserves the distinctions relevant to a statistical task. Coordinate changes can simplify an invertible description, while a nontrivial kernel is an actual loss of distinguishability on the chosen domain.
