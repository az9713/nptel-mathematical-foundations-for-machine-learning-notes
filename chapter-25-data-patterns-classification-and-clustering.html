25. Data, patterns, classification, and clustering

A dataset does not specify its own question. The same measurements can support classification, regression, or clustering depending on the target and the loss. A useful analysis therefore begins by deciding what one observation means, which information is available when a prediction is made, and what would count as a good answer on new data.

Lecture spine: Lectures 65–67. The lectures' qualitative examples motivate the distinctions below. All numerical tables and calculations here are original constructions, not reconstructions of ambiguous captioned counts or measurements. Domain illustrations do not establish diagnostic rules or universal performance percentages.

25.1 From a real problem to a learning problem L65 · 02:46

A data-driven method uses observations to select or fit a rule for a task. That rule still contains modeling choices: the observation unit, the measurement process, the allowed predictor family, and the objective. Classical physical models and fitted data models can complement each other. For instance, a known conservation constraint can restrict a regression model, while measurements estimate its remaining coefficients. Replacing a differential equation by a dataset does not remove the need for assumptions.

Write $x_i\in\mathbb R^d$ for the measured features of observation $i$. A supervised example also includes a target $y_i$. For classification $y_i$ lies in a finite class set; for regression it is typically numerical. Unsupervised observations have no supplied target for the task. Clustering seeks a grouping based on a chosen notion of similarity. It is one form of unsupervised learning, alongside density estimation and dimension reduction.

A feature and a label are not synonyms. A measured color, temperature, or spectral coefficient is a feature; a separately annotated class can be the label. Whether a feature is distinctive does not determine whether data are labeled. The same feature vector is labeled when paired with an observed training target and unlabeled when that target is unavailable. A continuous target is also a label in the broad supervised-learning usage, so labeled data do not imply classification alone.

The lecture emphasizes quantity, quality, and domain knowledge. They address different problems. More independent observations can reduce sampling uncertainty under a stable measurement process. They cannot by themselves repair a sensor that always adds a constant bias, systematically missing cases, or labels generated from the wrong definition. With measurements $x_i=\mu+\delta+\varepsilon_i$, where $\mathbb E\varepsilon_i=0$ and $\operatorname{Var}(\varepsilon_i)=\sigma^2$, the mean has expectation $\mu+\delta$ and variance $\sigma^2/n$ for independent noise. Increasing $n$ shrinks the variance while leaving bias $\delta$ intact.

Stored records, streams, and sensor data differ in acquisition and timing. Domain knowledge helps determine which measurements are meaningful, how errors arise, and what an action should accomplish. Optimization then finds a good value of the specified objective over the specified model family. It cannot certify that the objective captures the original problem. The lecture's broad prevalence percentages are motivational remarks rather than measurements used in this chapter.

25.2 Feature maps can simplify geometry L66 · 01:21

Let $\phi:\mathcal X\to\mathbb R^m$ map raw observations to features. A binary classifier can take the form $\widehat y(x)=\mathbf1\{w^\top\phi(x)+b\ge0\}$. Its boundary is affine in feature space, but can be curved in the original space. This formalizes the lecture's progression from data space through feature space to an action or event.

Consider two classes defined by radius in the plane: the inner class satisfies $x_1^2+x_2^2\lt 1$ and the outer class satisfies $x_1^2+x_2^2\gt 1$. No single straight line separates a complete inner disk from a complete surrounding ring. Yet the scalar feature $\phi(x)=x_1^2+x_2^2$ permits the threshold rule $\mathbf1\{\phi(x)\ge1\}$. A nonlinear feature map made the final classifier simple. By contrast, an arbitrary spiral arrangement is not automatically untangled by this radius feature; the transformation must match the geometry.

A feature map can also destroy information. If $\phi(x)=\phi(x')$ but the targets differ, no deterministic classifier depending only on $\phi$ can classify both correctly. In a noisy population, overlapping class-conditional feature distributions can create irreducible error for any rule using those features. Increasing model complexity cannot recover information that was never measured.

Adding candidate features enlarges some model families, so the best achievable training error cannot increase when the old rule remains available. This does not imply improved test error. A fitted rule can exploit accidental correlations, and additional measurements can add noise, missingness, or cost. Even a deterministic transform of existing features can change the simplicity of the available decision rule without adding information. Feature quality and useful representation are related but distinct ideas.

For counts $a_s,b_s$, the number of errors is $E(t)=\sum_{s\ge t}a_s+\sum_{s\lt t}b_s$. Prediction changes only when a threshold crosses an observed score, so all distinct threshold classifiers can be checked using the intervals before, between, and after the five scores. Thresholds $-0.5,0.5,1.5,2.5,3.5,4.5$ give error counts $9,5,3,4,6,10$. The best training choice is any $t\in(1,2]$, giving the same predictions as $t=1.5$ and error rate $3/19$.

At $t=1.5$, two state-A observations are predicted B, one state-B observation is predicted A, and 16 are correct. Taking B as the positive class gives true positives 9, false negatives 1, false positives 2, and true negatives 7. Recall is $9/10$ and precision is $9/11$. These are conditional proportions with different denominators; neither equals overall accuracy $16/19$. Reporting that one class is perfectly recovered would say nothing about the other class's error.

If the two error types have different costs, minimize $C(t)=c_{A\to B}\sum_{s\ge t}a_s+c_{B\to A}\sum_{s\lt t}b_s$ instead. Class frequencies and costs can change the preferred threshold. More generally, if $p(x)=P(Y=B\mid x)$ is known and correct decisions cost zero, predicting B has expected cost $c_{A\to B}(1-p)$, while predicting A has cost $c_{B\to A}p$. Therefore choose B when $p\ge c_{A\to B}/(c_{A\to B}+c_{B\to A})$. A probability of one half is a special equal-cost case.

25.4 Separate fitting, selection, and final evaluation L67 · 02:37

Let $\widehat R_{\mathcal D}(f)=|\mathcal D|^{-1}\sum_{(x,y)\in\mathcal D}\ell(y,f(x))$ be empirical risk on a finite sample, with specified loss $\ell$. The intended population risk is $R(f)=\mathbb E[\ell(Y,f(X))]$ under the deployment distribution. Training adjusts model parameters; validation selects features, thresholds, hyperparameters, or stopping time; the final test set estimates performance after those decisions are fixed. Terminology varies between sources, but these information roles should not be blurred.

The smallest training error after searching many rules is optimistic because the same data chose the rule and measured it. Choosing the threshold in the preceding table does not make $3/19$ an unbiased estimate of future error. The general distinction between fitted risk and unseen-data risk is developed in Deisenroth, Faisal, and Ong, §§8.1.4–8.2.3, printed pages 257–263. Using a test curve to choose an epoch turns that curve into selection information; a separate final evaluation is then needed.

In $K$-fold cross-validation, partition the available development observations into $K$ disjoint folds. For each fold, fit the complete pipeline on the other $K-1$ folds and evaluate on the held-out fold. Average the resulting losses, weighting by fold size when needed. Standardization, imputation, feature selection, and any learned transformation must be fitted within each training fold. Fitting them once on all observations leaks information even if the final classifier sees only its designated training rows. See §8.2.4, printed pages 263–264 for the fold construction.

A random row split is suitable only when it represents the intended prediction setting. Repeated measurements from the same device or subject can require grouped splits. Forecasting requires respecting time: using future records to choose a feature transform can invalidate an online prediction estimate. An independent external dataset tests a particular distribution shift; it does not make a model universally valid. Repeatedly tuning against that dataset also consumes its independence.

The lecture sketches error first falling and then rising as features or training time increase. These are useful illustrations of overfitting, not inevitable shapes of every learning curve. Underfitting means the procedure misses useful structure; overfitting means its fit to the available sample does not transfer well. Select model complexity using the intended evaluation protocol rather than assuming that either the smallest or largest feature set must win.

25.5 Multiple classes and classifier fusion L66 · 07:28

A multiclass problem can be organized as a hierarchy of binary decisions, as the lecture illustrates. It can also be modeled directly with several scores, one-vs-rest rules, or other constructions. A hierarchy makes a sequence of decisions; an early routing error can prevent the correct class from ever being considered. A balanced tree has roughly logarithmic path length in its number of leaves, but choosing its groups and learning each decision remain substantive tasks.

A panel of classifiers can combine hard votes, real-valued scores, or estimated probabilities. For example, $p(x)=\sum_{j=1}^M\alpha_jp_j(x)$ with $\alpha_j\ge0$ and $\sum_j\alpha_j=1$ stays in $[0,1]$ if each $p_j$ does. This algebra alone does not establish calibration or improved accuracy. Weights and the final threshold should be selected using development data, and the combined rule evaluated once on the held-out test data.

The value of diverse errors can be seen in a restricted calculation. If three binary classifiers have independent error events at a fixed problem distribution, each with error probability $p$, majority voting errs with probability $3p^2(1-p)+p^3=3p^2-2p^3$. For $p=0.2$ this is $0.104$. If their errors are identical rather than independent, majority voting has error $0.2$. The independence calculation explains a possible benefit, not an automatic guarantee for real classifiers trained on the same sample. The lecture's second-opinion analogy motivates aggregation; it does not supply evidence for any particular domain intervention.

25.6 Clustering starts with geometry, not recovered truth L67 · 10:51

Given unlabeled points $x_1,\ldots,x_n$, a clustering specifies groups or soft memberships. It does not usually discover a unique, preexisting list of semantic classes. Groupings can differ by purpose: shape, location, behavior, or another relevant similarity. Assigning a descriptive name after inspecting a group does not prove that the group equals a supervised ground-truth class.

A metric $d(x,y)$ is nonnegative, symmetric, zero exactly when $x=y$, and satisfies the triangle inequality. Euclidean distance is a metric. Squared Euclidean distance is not: for real points 0,1,2, one has $d^2(0,2)=4\gt 1+1$. A dissimilarity used by an algorithm need not be a metric, but its assumptions should be explicit. For nonzero vectors, cosine similarity is $s(x,y)=x^\top y/(\|x\|\|y\|)$. It compares directions and ignores positive rescaling. The zero vector needs a separate convention; cosine similarity is not generally the same as correlation, which additionally centers components.

Units alter Euclidean geometry. Consider $(0,0),(0,2),(8,0),(8,2)$. Dividing into left and right pairs gives within-group squared error 4, while dividing into bottom and top pairs gives 64. If the first coordinate is rescaled by 0.1, those totals become 4 and 0.64, reversing which partition is preferred. Standardization is one possible modeling choice, not a universal correction: a low-variance feature may be important, and a large-variance feature may reflect meaningful scale.

The lecture's compactness-within and separation-between intuition is valuable for centroid methods. It can be misleading for curved or connected groups: points along a long arc may belong together despite a distant centroid. Choosing a metric and an objective specifies what kind of structure the procedure is designed to find.

25.7 Make the centroid method into a precise optimization problem L67 · 18:18

The captions sketch random centers, radii, and merging rather than one fully specified algorithm. A precise, related centroid method is $K$-means. Fix $1\le K\le n$, assign each point a group $c_i\in\{1,\ldots,K\}$, and minimize

$$J(c,\mu)=\sum_{i=1}^n\|x_i-\mu_{c_i}\|_2^2.$$

For fixed centers $\mu_1,\ldots,\mu_K$, assigning each point to a nearest center cannot increase $J$. For fixed nonempty groups, their optimal centers are means. To prove this, let $\bar x_k$ be the mean of a group $C_k$. Expanding around its mean gives

$$\sum_{i\in C_k}\|x_i-\mu\|^2=\sum_{i\in C_k}\|x_i-\bar x_k\|^2+|C_k|\|\mu-\bar x_k\|^2,$$

because $\sum_{i\in C_k}(x_i-\bar x_k)=0$. The mean minimizes the expression, uniquely for a nonempty group. Alternating nearest-center assignments and mean updates is Lloyd's algorithm. Both steps decrease or preserve the same nonnegative objective. This proves monotonicity of objective values; it does not prove a global optimum. Tie handling and empty-group handling must be specified in an implementation. The scikit-learn clustering guide describes this objective and initialization sensitivity.

For the one-dimensional points $0,2,8,10$, start with centers 0 and 3. The first assignment groups $\{0\}$ and $\{2,8,10\}$, whose means are 0 and $20/3$. The next assignment groups $\{0,2\}$ and $\{8,10\}$, giving means 1 and 9 with squared error 4. A further iteration is unchanged. This example supplies a complete update rule in place of an unspecified radius heuristic.

For a fixed dataset, the best $K$-means objective cannot increase when another center is allowed. At $K=n$ it can be zero, so raw within-group error alone cannot choose $K$. A one-group answer or a singleton partition is mathematically valid; whether it is useful depends on the task. Stability, domain usefulness, and criteria that account for complexity can guide selection. A random search over $K$ does not guarantee finding a uniquely correct grouping.

25.8 Hierarchies, mixtures, and what “between” means L67 · 20:40

For a fixed $K$, a partition has within-group scatter $W=\sum_k\sum_{i\in C_k}\|x_i-\bar x_k\|^2$. Let $\bar x$ be the overall mean and $B=\sum_k |C_k|\|\bar x_k-\bar x\|^2$. Expanding each $x_i-\bar x=(x_i-\bar x_k)+(\bar x_k-\bar x)$ cancels cross terms and gives the identity $T=W+B$, where $T=\sum_i\|x_i-\bar x\|^2$ is fixed. Thus minimizing this particular within scatter maximizes this particular weighted between scatter. It does not maximize every pairwise distance between centers, and it is not an additional independent minimax objective.

Agglomerative hierarchical clustering begins with small groups and merges according to a specified linkage, such as the smallest pairwise distance or an increase in within-group scatter. The linkage determines the hierarchy. A Gaussian mixture instead models a density $p(x)=\sum_{k=1}^K\pi_k\mathcal N(x\mid\mu_k,\Sigma_k)$ with nonnegative mixing weights summing to one. Covariance matrices can represent elliptical components, and posterior component probabilities provide soft memberships. The model and normalization are introduced in Deisenroth, Faisal, and Ong, §11.1, printed pages 349–350.

These methods express different assumptions. A mixture component need not equal a semantic class, and an arbitrary nonconvex group need not be represented well by one Gaussian. Likelihood-based fitting also requires safeguards against degenerate covariances. Clustering is useful when the grouping criterion matches the purpose, not because unlabeled data necessarily possess a single obvious answer.

25.9 Executable check: thresholds and rescaling

The code reproduces the constructed threshold risks, demonstrates the geometry reversal under a unit change, and runs the complete centroid example. Its four-point Lloyd run has no ties or empty groups; it is deliberately not a general production implementation.

import numpy as np
scores = np.array([0, 1, 2, 3, 4])
A = np.array([4, 3, 1, 1, 0])
B = np.array([0, 1, 2, 3, 4])
errors = []
for t in [-0.5, 0.5, 1.5, 2.5, 3.5, 4.5]:
    err = int(A[scores >= t].sum()+B[scores < t].sum())
    errors.append((t, err))
print('threshold errors:', errors)
X = np.array([[0., 0.], [0., 2.], [8., 0.], [8., 2.]])
for name, Y in [('original', X), ('rescaled', X*np.array([0.1, 1.]))]:
    vertical = np.array([0, 0, 1, 1])
    horizontal = np.array([0, 1, 0, 1])

    def sse(labels):
        return sum(np.sum((Y[labels == k]-Y[labels == k].mean(axis=0))**2)
                   for k in [0, 1])
    print(
        f'{name} vertical_SSE={
            sse(vertical):.2f} horizontal_SSE={
            sse(horizontal):.2f}')
Z = np.array([0., 2., 8., 10.])
centers = np.array([0., 3.])
for step in range(3):
    labels = np.argmin((Z[:, None]-centers)**2, axis=1)
    centers = np.array([Z[labels == k].mean() for k in [0, 1]])
    objective = np.sum((Z-centers[labels])**2)
    print(f'Lloyd {step}: centers={centers} SSE={objective:.6f}')

25.10 Six worked problems

Problem 1: more data with a biased sensor

Problem. A sensor reports $X_i=\mu+2+\varepsilon_i$ with independent zero-mean errors of variance 9. Compute the mean-squared error of its sample mean as an estimator of $\mu$ for $n=9$ and $n=900$.

Solution

The sample mean has bias 2 and variance $9/n$. Its mean-squared error is variance plus squared bias, $9/n+4$. At $n=9$ the result is 5; at $n=900$ it is 4.01. Increasing the sample one hundredfold greatly reduces random fluctuation but leaves almost all the remaining error. Correcting the known offset gives the estimator $\bar X-2$, with mean-squared error $9/n$. This correction requires knowledge of the measurement process, illustrating why domain information can matter more than additional records.

Problem 2: change the cost, change the threshold

Problem. For the score table above, assign cost 1 to predicting B for state A and cost 4 to predicting A for state B. Compare all six threshold rules.

Solution

For increasing thresholds, the pairs $(\text{A predicted B},\text{B predicted A})$ are $(9,0),(5,0),(2,1),(1,3),(0,6),(0,10)$. Costs are consequently $9,5,6,13,24,40$. The cost-minimizing threshold is $t=0.5$, rather than the unweighted-error choice $1.5$. Its five total errors exceed three, but all five are of the cheaper kind. The relevant criterion must be specified before optimizing or announcing a best classifier.

Problem 3: an informative feature map that loses something

Problem. Can the feature $\phi(x)=x_1^2+x_2^2$ distinguish the two points $(1,0)$ and $(-1,0)$ if they have different class labels? How does this coexist with the disk-versus-ring example?

Solution

Both points map to 1. Any deterministic function $g(\phi(x))$ must therefore give the same prediction for them, so at least one is wrong. The disk-versus-ring labels depend only on radius and are preserved by $\phi$. The new labels depend on information about direction that $\phi$ discards. A useful representation is task-dependent; making one boundary simple can make another task impossible with the same features.

Problem 4: locate the information leak

Problem. A researcher standardizes all data, selects the ten features most correlated with all labels, performs five-fold validation on those features, and chooses the best epoch using the final test set. Which steps must change?

Solution

Both standardization statistics and the label-dependent feature selection must be fitted separately inside each training fold. The corresponding held-out fold is transformed using those fitted statistics and selected columns, without using its labels for selection. Epoch choice is a hyperparameter and must use validation information, not the final test set. After selecting the pipeline, it can be refitted on the development data and evaluated on a reserved test set. If the original test set already influenced the epoch choice, its reported result should be described as selection performance and a new untouched evaluation sought. Merely shuffling the already selected features does not undo the leakage.

Problem 5: derive and execute one centroid update

Problem. For points $0,2,8,10$, centers 0 and 3, and nearest-center assignment, compute the next two mean updates and their objectives. Explain why assigning every point its own center is insufficient to select the number of clusters.

Solution

Initially 0 is nearest the first center, while 2,8,10 are nearest 3. Their updated means are 0 and $20/3$. The residual sum is $(2-20/3)^2+(8-20/3)^2+(10-20/3)^2=104/3$. The new boundary is $10/3$, so the groups become $\{0,2\}$ and $\{8,10\}$. Their means are 1 and 9, giving objective $1+1+1+1=4$. Four singleton centers would give zero. Since adding centers can reduce within-group error even without finding useful structure, that error alone rewards the most complex partition and cannot choose $K$.

Problem 6: calculate both scatters and expose a unit choice

Problem. For $(0,0),(0,2),(8,0),(8,2)$, calculate total, within, and between scatter for the left/right partition. Then explain the reversal after rescaling the first coordinate by 0.1.

Solution

The overall mean is $(4,1)$. Every point has squared distance 17 from it, so $T=68$. The group means are $(0,1)$ and $(8,1)$, with within scatter $W=4$. Their squared distances from the overall mean are 16, each weighted by group size two, so $B=64$ and $T=W+B$. Under rescaling, the means become $(0,1)$ and $(0.8,1)$ and the total scatter becomes $4.64$. The left/right partition still has $W=4$, but the bottom/top partition has $W=0.64$. The algorithm's preference follows the chosen units, even though the four observations retain their identities. Choosing a meaningful metric is part of modeling.

25.11 What a reported result must mean

A classification result is meaningful only with its features, target definition, error costs, and evaluation split. A clustering result is meaningful only with its representation, similarity, objective, and choice of complexity. Labels are supplied task information; cluster identifiers are outputs of a procedure. Neither a large dataset, a simple-looking boundary, nor an optimized training score removes these distinctions.
